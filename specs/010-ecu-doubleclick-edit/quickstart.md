# Quickstart: 010 の検証

## 1. コアの検証（自動、checks.exe）

- ECU 数 1〜16 × DPI 96 / 120 / 144 で、各 ECU の箱の換算後の矩形について:
  - 内側の四隅（左上、右上 − 1 px、左下 − 1 px、右下 − 1 px）と中心で `FindEcuAt` がその ECU 番号を返す。
  - 外側 1 px（左 − 1、上 − 1、右、下）では、その ECU 番号を返さない。
- 96 dpi 基準のバス線の中央 (570, 110)、「CAN BUS」の文字の中心 (66, 93)、各接続線の中点、構成図の右下の余白 (1135, 210) を換算した点で 0。ECU 数 0 では構成図内のどこでも 0。
- `ScaleToDpi` が `(px * dpi + 48) / 96` と一致する（0〜1140 px × 各 DPI）。
- 既存の 001〜009 の項目が PASS のまま。CSV が変わらない。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー、ダブルクリックは実マウス入力）

1. `sample_appendix_a` を読み込み、「ECU 03」をダブルクリック → 編集ウィンドウが開き、選択欄が「ECU 03」。メインウィンドウのログ表示エリアも操作できる。
2. 開いたまま「ECU 05」をダブルクリック → 今のウィンドウが閉じ、0.4〜0.7 秒後に選択欄「ECU 05」で開く（閉じた時刻と開いた時刻を計測）。
3. 開いたまま「ECU 05」をもう一度ダブルクリック → 閉じ直さない（ウィンドウのハンドルが同じ）。
4. 選択欄で「ECU 01」に変えてから「ECU 01」をダブルクリック → 閉じ直さない。「ECU 03」をダブルクリック → 閉じて ECU 03 で開き直す。
5. 「ECU 03」→ すぐ「ECU 05」→ 待ちの間に「ECU 06」をダブルクリック → 開くのは ECU 06 の 1 つだけ（`sample_appendix_a` は ECU 数 6 なので ECU 07 は無い）。
6. 開いている間（と待ちの間）: 「シミュレーション → 開始」がグレー。閉じると選べる。
7. 開いている間に「セッティング」→ 編集ウィンドウが閉じてからセッティングが開く。「プロジェクト読込み」も同様。
8. 「追加」の入力画面を開いたまま構成図の別の ECU をダブルクリック → 何も起きず、入力画面は残る（メインウィンドウは無効）。
9. ECU 03 にフレームを追加 → ECU 05 に切り替え → 保存したプロジェクトに ECU 03 の追加が残る。メニューから開いて同じ操作をしたものと同じ内容。
10. バス線・「CAN BUS」の文字・接続線・構成図の余白・ログ表示エリアのダブルクリックで何も開かない。ECU の 1 回クリックでも開かない。
11. `sample_startup`（スピード 0）の実行中に ECU をダブルクリック → 開かず、実行が続く。完了後は開ける。
12. 待ちの間にメインウィンドウを ✖ で閉じる → 新しい編集ウィンドウは開かず、プロセスが終了する。
13. 編集ウィンドウが開いていないときにメニュー「編集 → データフレーム編集」→ ECU 01 で開く。開いているときは前面に出るだけ。
14. ECU 03 の箱の縁の内側 1 px（左上から (+1, +1)）でダブルクリックすると開き、外側 1 px（(−1, −1)）では開かない（拡大率 100%）。
15. 開いた編集ウィンドウが構成図の ECU（ECU 01〜16）に重ならず、構成図の下に出る。編集ウィンドウで Tab が効き、Esc で閉じる。メインウィンドウは Enter・Esc で閉じない。
16. 「追加」の入力画面を閉じた後、メインウィンドウ（構成図のダブルクリック、メニュー）が再び操作できる。
