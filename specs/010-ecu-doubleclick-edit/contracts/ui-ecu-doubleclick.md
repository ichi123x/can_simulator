# UI Contract: 構成図の ECU ブロックのダブルクリックと編集ウィンドウの切り替え

## 入力

- メインダイアログのクライアント領域での左ボタンのダブルクリック（OS 標準の判定）。座標はクライアント座標。

## 判定（ダブルクリック時）

1. シミュレーション実行中なら何もしない（FR-006）。
2. `k = FindEcuAt(ComputeBusDiagramLayout(表示中の ECU 数), x, y, 画面の DPI)`。0 なら何もしない（FR-005）。
3. 編集ウィンドウの状態（data-model.md の状態遷移）に従う:
   - 閉: ECU k を選んだ編集ウィンドウを開く（FR-001、FR-002）。
   - 開・表示中の ECU = k: 閉じずに前面に出す（FR-011）。
   - 開・表示中の ECU ≠ k: 今の編集ウィンドウを閉じ、500 ms 後に ECU k で開く（FR-010）。
   - 待ち: 開く予定を k に置き換える（開くのは閉じてから 500 ms 後のまま、FR-012）。
4. 編集ウィンドウが入力画面・削除確認を出している間は、メインウィンドウが無効なのでダブルクリックは届かない（FR-015）。

## 編集ウィンドウ

- 内容・ボタン・検査・プロジェクトへの反映は機能 006 と同一。選択欄で別の ECU に切り替えられ、切り替え後はその ECU が「表示中の ECU」。
- 開いたままメインウィンドウを操作できる（FR-009）。同時に 1 つだけ。常にメインウィンドウの前面に表示される。
- 開く位置は構成図の下（ログ表示エリアの左端・構成図の下端の 8 px 下が左上）。画面の作業領域からはみ出す場合は収まるようずらす（FR-017）。
- Tab で項目間を移動でき、Esc・Enter・「閉じる」・✖ で閉じる。メインウィンドウは従来どおり Enter・Esc では閉じない。
- 「閉じる」・Esc・✖ で閉じる。どの経路で閉じても、それまでの編集はプロジェクトに残る（FR-016）。

## メインウィンドウのメニュー（編集中 = 開いている、または待ち）

| 項目 | 編集中の扱い |
|---|---|
| シミュレーション → 開始 | グレー（選べない）（FR-013） |
| ファイル → プロジェクト読込み | 編集ウィンドウを閉じ（待ちは取り消し）、その後に読込み（FR-014） |
| 編集 → セッティング | 同上 |
| 編集 → データフレーム編集 | 開いていれば前面に出す。待ちの間は何もしない |
| ファイル → プロジェクト保存、編集 → フレーム表示 | そのまま使える |

## メインウィンドウを閉じる（✖）

- 編集ウィンドウも閉じる。待ちの間なら新しい編集ウィンドウは開かない。

## 変えないもの

- 編集ウィンドウが開いていないときのメニューからの開き方（ECU 01）。
- シングルクリック、ログ表示エリアのスクロール・ホイール操作（機能 009）。
- 構成図の位置・大きさ・色（機能 003）。実行中のメニュー制限（機能 007）。
