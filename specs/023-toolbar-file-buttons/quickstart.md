# Quickstart: ツールバーの保存・読込みボタンの確認

## 前提

- 4 構成（Debug/Release × x86/x64）でビルドが通っていること（CLAUDE.md のビルド節）。
- checks をビルドして全項目が通ること（CLAUDE.md の検証ツール節）。023 の項目は座標・当たり判定・有効／無効を確かめる（[contracts/ui-toolbar-file-buttons.md](./contracts/ui-toolbar-file-buttons.md)）。

## 手動確認（GUI）

1. **並び**: 起動直後のツールバーが、左から 保存・読込み・空き・開始・中断・終了・フレーム表示・シミュレーション時間・スピード：・スライダー の順で、重なりがないこと（spec FR-001・FR-002、SC-004）。表示の拡大率 100%・125%・150% で確かめる。
2. **保存（ファイルなし）**: 起動直後に「保存」を押すと保存先を尋ねられる。キャンセルすると何も起きず、もう一度押すとまた尋ねられる（US1-1・2）。保存すると、指定したファイルができる。
3. **保存（ファイルあり）**: 2 の後に、スピードを変えてから「保存」を押す。尋ねられずに上書きされ、ファイルの `Speed=` が変わっていること（US1-3）。
4. **保存の失敗**: 3 のファイルを読み取り専用にして「保存」を押すと、保存エラーのメッセージが出ること（US1-4）。確かめたら読み取り専用を外す。
5. **メニューの保存は変わらない**: ファイルがあっても「ファイル → プロジェクト保存」は保存先を尋ねること（FR-008）。
6. **読込み**: 「読込み」から `MFCApplication1/CanSim/SampleConfigs/sample_16ecu.canprj` を開き、構成図が 16 ECU になること。メニューから読み込んだ場合と同じ表示になること（US2-1、SC-002）。続けて「保存」を押すと、尋ねられずにこのファイルへ上書きされること。
7. **読込みのキャンセル・エラー**: キャンセルで何も変わらないこと、拡張子の違うファイルでエラーが出ること（US2-2・3）。
8. **編集中**: ECU をダブルクリックして編集ウィンドウを開いた状態で、次を確かめる（US2-4、Edge Cases）。
   - 「保存」: 押せて、編集ウィンドウは閉じない。
   - 「読込み」: 先に編集ウィンドウが閉じてからファイル選択が開く。
9. **実行中・中断中**: 「開始」後と「中断」後に、保存・読込みがグレーで、押しても何も開かないこと。終了後に元に戻ること（US3）。
10. **押し方**: 「保存」を押したまま「読込み」の上へ動かして離すと、どちらも動かないこと（Edge Cases）。
11. **既存の動作**: 開始・中断・終了・フレーム表示・スライダーが新しい位置で今までどおり動くこと（FR-008）。
