# Quickstart: 007 の検証

## 1. コアの検証（自動）
`checks.exe` をビルド・実行（CLAUDE.md の手順）。追加項目: `sample_collision` を 125k / 250k / 500k / 1M で実行し、
連続する 2 フレームの Tx_Start − 前の Tx_End が 3 ビット時間（24 / 12 / 6 / 3 µs）であること（送信待ちが続く場合）、
それ以外でも 3 ビット時間以上であること、伝送時間がビット数 × ビット時間に一致すること。既存項目がすべて PASS のまま。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー）
1. 停止中: 「ファイル」「編集」「シミュレーション」が開ける。
2. スピード 0・10 秒で開始 → 実行中に「ファイル」「編集」がグレー。クリック（`SC_KEYMENU`）と Alt+F / Alt+E で開かない。
   「シミュレーション」は開け、「終了」だけ選べる。
3. 完了後、「ファイル」「編集」が開ける。途中で「終了」した場合も同様。
4. フレーム表示 ON で開始 → 実行中も強調が続く。

## 3. ビルド
Debug/Release × x64/x86 の 4 構成で警告なし。
