# UI Contract: メニュー、セッティング、再生表示

## メニュー
| メニュー | 項目 | ID | 有効条件 |
|---|---|---|---|
| ファイル(&F) | プロジェクト読込み(&O)... | ID_FILE_LOAD_PROJECT | 停止中 |
| ファイル(&F) | プロジェクト保存(&S)... | ID_FILE_SAVE_PROJECT | 常に |
| 編集(&E) | セッティング(&T)... | ID_EDIT_SETTINGS | 停止中 |
| 編集(&E) | フレーム表示(&D) | ID_EDIT_FRAME_DISPLAY | 常に（チェック=ON） |
| シミュレーション(&S) | 開始(&R) | ID_SIM_START | 停止中 |
| シミュレーション(&S) | 終了(&X) | ID_SIM_STOP | 実行中のみ |

トップレベルのニーモニックは F／E／S で衝突しない。サブメニュー内のニーモニックは、それぞれの
メニュー内で一意。

## セッティング画面
| コントロール | 内容 |
|---|---|
| ECU 数 | ドロップダウンリスト、0〜16 |
| 通信速度 | ドロップダウンリスト、125 kbps / 250 kbps / 500 kbps / 1 Mbps |
| シミュレーション時間(秒) | 数字入力、1〜600。範囲外は OK 時にメッセージ表示で閉じない |
| OK / キャンセル | OK で反映、キャンセルは変更なし |

## 再生表示（フレーム表示 ON）
| 状態 | 表示 |
|---|---|
| 送信元 ECU | 赤系の塗り（濃）、枠を太く |
| 受信 ECU | 緑系の塗り |
| バス線 | 送信中は青系に太く強調、送信元の接続線も同色 |
| 待機中の ECU | 003 の通常色 |
| 1 フレームの表示時間 | 250 ms（定数）、空き時間は飛ばす |
| 停止時 | 通常表示に戻す |

## 通知メッセージ（文字列テーブル）
完了（出力ファイル名を含む）／プロジェクトの読込みエラー（理由）／保存エラー／セッティングの
入力エラー／上書き確認。すべて `.rc` の日本語文字列。
