# Quickstart: 004 の検証

## 1. コアの検証（自動）
CLAUDE.md の手順で `checks.exe` をビルド・実行（サンプルは `.canprj` に移行後）。追加項目:
`.canprj` 読込み（既定値、範囲外の拒否、ノード 0 個の許容）、保存→再読込みの一致（SC-003）、
`BuildRunNetwork`（ECU 増減時の補完と切り捨て、FR-011）、`BuildFrameEvents`（送信元・受信者・並び）、
既存サンプルの結果が 001・002 と一致（SC-009）、終了時刻 t の再実行で「t までに送信を完了した
フレームだけ」になること（SC-008）。

## 2. GUI の目視確認（Debug|x64 でビルドし起動）
1. 起動直後: タイトルバー直下にメニュー 3 項目、その下が白で ECU 2 個の構成図。ボタン・入力欄なし（SC-001/007）。
2. 編集→セッティング: ECU 数 17 通り、通信速度 4 通り。ECU 数 16 で決定 → 16 個表示。キャンセル → 変化なし。時間に 0 を入力 → 拒否。
3. ファイル→プロジェクト保存 → 再起動 → 読込みで一致（SC-003）。壊れたファイル・範囲外の値 → 理由表示で変化なし（SC-004）。
4. `sample_appendix_a.canprj` を読込み、シミュレーション→開始 → 完了通知、3 種の CSV が出力される（フレーム表示 OFF）。
5. 編集→フレーム表示 ON で開始 → 送信元・受信・バスが順に強調される。途中で終了 → 強調が消え、その時点までの結果が出力される（SC-005/008）。
6. ON と OFF で同じ構成を実行し、3 種の CSV が同一であることを比較（SC-006）。
7. Enter / Esc でダイアログが閉じない。✖ では閉じる（実行中は結果を出力しない）。
