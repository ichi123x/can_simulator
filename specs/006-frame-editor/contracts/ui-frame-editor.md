# UI Contract: データフレーム編集

## メニュー
| メニュー | 項目 | ID | 有効条件 |
|---|---|---|---|
| 編集(&E) | データフレーム編集(&F)... | ID_EDIT_FRAMES | 停止中（「セッティング」の下） |

## 編集ウィンドウ（IDD_FRAME_EDIT、モーダル）
| コントロール | 内容 |
|---|---|
| ノード | ドロップダウンリスト「ECU 01」〜「ECU NN」（NN = ECU 数）。初期選択は ECU 01 |
| 一覧 | レポート表示、1 行選択。列: No. / フレーム名 / ID / DLC / 初回オフセット(ms) / 送信周期(ms)。ID は `0x100` 形式 |
| 追加 | 一覧が 100 件のとき、または ECU 数 0 のとき無効 |
| 編集 | 行が選ばれていないとき無効。一覧のダブルクリックでも同じ動作 |
| 削除 | 行が選ばれていないとき無効。確認「No.n フレーム名 (0xXXX) を削除しますか？」 |
| 閉じる | ウィンドウを閉じる（変更は既にプロジェクトへ反映済み） |

## 入力画面（IDD_FRAME_ENTRY、モーダル）
| コントロール | 内容 |
|---|---|
| フレーム名 | テキスト、最大 32 文字 |
| ID | テキスト（16 進、`0x` 省略可） |
| DLC | テキスト（数字） |
| 送信周期(ms) | テキスト（数字） |
| 初回オフセット(ms) | テキスト（数字）、初期値 0 |
| ビット長 / 伝送時間 | 表示のみ。「132 ビット / 264 µs」形式。ID・DLC が範囲外なら「-」 |
| OK / キャンセル | OK で検査。NG は「項目: 理由」を行ごとに示すメッセージを出し、最初の NG 項目にフォーカスして閉じない |

## メッセージ（文字列テーブル、日本語）
項目名（フレーム名、ID、DLC、送信周期、初回オフセット）と理由（未入力、数値ではない、範囲外（範囲を示す）、他の
フレームと重複（重複先のノードと通し番号を示す）、長すぎる、送信周期以上）、削除の確認。
