# Contract: 起動記録（出力）

ドメイン仕様書 FR-053 に従い、起動状態遷移はフレームログとは**別ファイル**に出力する。形式は機能 001 のログ・集計サマリと揃えて CSV（UTF-8、ヘッダ行あり）とする。

## ファイル名・配置

フレームログ・集計サマリと同じ規則で、読み込んだ設定ファイルのパスを基準に決定する。

| 出力 | ファイル名 |
|---|---|
| フレームログ（機能 001） | `<設定ファイル名>.log.csv` |
| 集計サマリ（機能 001） | `<設定ファイル名>.summary.csv` |
| **起動記録（本機能）** | **`<設定ファイル名>.startup.csv`** |

## 列定義（ヘッダ順）

```
Node_Id,Node_Name,Power_On_us,Init_Done_us,Normal_Entry_us,Reached_Normal
```

| 列 | 型 | 説明 |
|---|---|---|
| `Node_Id` | 整数 | 設定上のノード番号（1〜16） |
| `Node_Name` | 文字列 | ノード名称。カンマを含む場合は二重引用符で囲む |
| `Power_On_us` | 整数（µs） | 設定された電源投入時刻 |
| `Init_Done_us` | 整数（µs）or 空 | 初期化が完了しバス同期検出に入った時刻。未到達なら空欄 |
| `Normal_Entry_us` | 整数（µs）or 空 | 通常動作に入った時刻。未到達なら空欄 |
| `Reached_Normal` | `TRUE` / `FALSE` | シミュレーション終了までに通常動作へ到達したか（FR-013） |

行はノード番号の昇順で出力する（再現性のため順序を固定する、FR-014）。

## 例

500 kbps（1ビット時間 = 2 µs、11ビット時間 = 22 µs）、ノード1は既定値、ノード2は電源投入 50 ms・初期化 1 ms、ノード3は電源投入がシミュレーション時間より後、という構成の場合:

```csv
Node_Id,Node_Name,Power_On_us,Init_Done_us,Normal_Entry_us,Reached_Normal
1,ECU1 Engine Control,0,0,22,TRUE
2,ECU2 Transmission,50000,51000,51022,TRUE
3,ECU3 ABS/Brake,9999000,,,FALSE
```

- ノード1: バスが空なので `0 + 0 + 22 = 22 µs` に通常動作へ入る（SC-003）。
- ノード2: `50000 + 1000 = 51000 µs` に検出を開始。その時点でバスが空なら `+22 µs`。他ノードの送信中なら、そのフレームのインターミッション終了時点になる（SC-004）。
- ノード3: 通常動作に到達せず、`Init_Done_us` / `Normal_Entry_us` は空欄、`Reached_Normal=FALSE`。

## 対応する要件

FR-011, FR-012, FR-013, FR-014
