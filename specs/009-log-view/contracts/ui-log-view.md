# UI Contract: ログ表示エリア

## 配置（96 dpi 基準、DPI/96 でスケール。参考画像 `Doc/ログ表示エリアイメージ図.jpg`）
| 項目 | 値 |
|---|---|
| ログ表示エリアの矩形 | 左 150 px、上 260 px、幅 850 px、高さ 260 px（構成図の下、左右に余白） |
| 背景 | `RGB(230, 230, 230)`（薄いグレー）、文字は黒、等幅フォント |
| スクロールバー | 矩形の右端の内側、縦、幅 17 px |
| クライアント高さ | 560 px（約 345 DLU）、幅は従来どおり |

## 行の書式
| 種類 | 例 |
|---|---|
| 状態遷移 | `      22 us  ECU 01  通常動作`（状態名: 初期化中／バス同期検出中／通常動作。将来: エラーアクティブ／パッシブ／バスオフ） |
| フレーム | `     274 us  ECU 03 -> ECU 01  0x080  DLC 8  正常`（状態: 正常／再送／破棄） |
| 受信ノードなし | `     274 us  ECU 03 -> -  0x080  DLC 8  正常` |

## 動作
| 項目 | 規則 |
|---|---|
| 追加 | 時刻順に上から下へ。実行中は再生時計（実経過時間 × 2^スピード）に合わせて追加、スピード +10 と完了時は全行 |
| スクロール | 一番下を見ているとき、1 行追加で 1 行上へ。過去を見ているときは動かさない。一番下へ戻すと追従を再開 |
| スクロールバー | 全行数に対するつまみ。行が収まるときは無効。ホイールは 3 行ずつ |
| クリア | 「開始」で消す。完了・終了・読込み・セッティング変更では消さない |
