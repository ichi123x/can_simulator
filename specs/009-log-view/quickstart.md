# Quickstart: 009 の検証

## 1. コアの検証（自動、checks.exe）
- `sample_startup`（6 ECU）: `BuildLogLines` の状態遷移が 18 行（ノード × 3）で、時刻が起動記録（Power_On / Init_Done / Normal_Entry）と一致。
- 並び順: 全体が時刻の昇順、同時刻は状態遷移が先、次にノード番号の昇順。
- フレーム行の数 = ログの行数（OVERWRITE を含む）。`durationUs` を超える状態遷移は含まれない。
- 既存の 001〜008 の項目が PASS のまま。CSV が変わらない。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー）
1. 起動直後: 構成図の下に薄いグレーの空のエリア（左右に余白）。
2. `sample_startup` をスピード 0 で実行: 状態遷移の行が時刻に合わせて上から下へ現れ、フレームの行が続く。
3. 表示エリアが埋まったあと、1 行追加ごとに 1 行ずつ上へスクロールし、最新行が一番下にある。
4. 実行中にスライドバーを上へ動かす: 過去の行が見え、10 行以上追加されても位置が動かない。一番下へ戻すと追従が再開。
5. 実行後にスライドバーを一番上へ: 最初の行（最初の電源投入）が見える。
6. スピード +10 で実行: 完了時に全行があり、スクロールバーで先頭まで読める。
7. `sample_16ecu` を実行して約 12 万行でも、スクロールバー操作が重くない。
8. もう一度「開始」: 前の行が消え、新しい実行の行が最初から。フレーム表示 ON/OFF で表示が変わらない。
