# Quickstart: 017 の検証

## 1. コアの検証（自動、checks.exe）

- 017 の新しい項目（DPI 96/120/144）:
  - 並び: 終了ボタンの右端 < チェックボックスの当たり判定 < スライダーの当たり判定 < 時刻の欄。互いに重ならない。
  - 範囲:
    - 全部が帯の中（高さ `ScaleToDpi(64)`）にある。
    - 時刻の欄の右端 ≤ `ScaleToDpi(kDiagramWidth)`。
    - チェック欄と文字は、当たり判定の中にある。
  - `IsOnFrameDisplayToggle`:
    - チェック欄の中央・文字の中央で真。
    - 終了ボタンの中央・スライダーの -13 の目盛りで偽。
  - `FormatSimTimeUs`: 0 → `0`、999 → `999`、1000 → `1,000`、10000000 → `10,000,000`、600000000 → `600,000,000`、-5 → `0`。
- 015 のスライダーの項目が、ずらした後の座標で PASS する。
- 既存の 001〜016 の項目がすべて PASS し、サンプルの CSV が基準と一致する。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー）

詳しい動作は [contracts/ui-toolbar-display-time.md](./contracts/ui-toolbar-display-time.md) を参照。

1. 起動直後:
   - ツールバーに ボタン → チェックボックス（チェックなし）→ スライダー → 「シミュレーション時間」「0」「μs」が並ぶ（画面写し）。
   - 「編集」メニューに「フレーム表示」が無い（メニュー項目の数と文字列）。
2. チェック欄をクリック → チェックが入る。文字をクリック → 外れる。
3. チェックありで `sample_appendix_a`（スピード -10）を実行し、バスが青の時点で中断する → 強調がある。チェックを外す → すぐ強調が消える。入れる → 戻る。
4. チェックなしで実行し、実行中にチェックを入れる → 0.5 秒以内に強調が出る。
5. スピード 0 で実行する。
   - 時刻の表示が増える。
   - 3 秒で中断し、5 秒待っても表示が変わらない。
   - 「終了」→ 表示の値が終了メッセージの時刻と一致する。
6. 自然終了（スピード +3 などで完了まで）→ 表示が `10,000,000`。スピード +10 で開始 → `10,000,000`。次の「開始」で 0 から。
7. 600 秒の構成をスピード +10 で実行する → `600,000,000` が欄からはみ出さない（画面写し）。
8. チェックありで保存し、外してから読み込み直す → チェックが入る。
