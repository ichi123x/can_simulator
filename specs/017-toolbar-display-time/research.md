# Research: 017 フレーム表示チェックボックスとシミュレーション時間の表示

## 決定1: チェックボックスは自前で描く

- **Decision**: 014・015 と同じく、`DrawSimToolbar` で描き、`OnLButtonDown` で押下を受ける。
  - 押した瞬間に反転する。離すのを待たない。スライダーと同じく、押した時点で反映する。
  - 素早い 2 回目のクリック（`OnLButtonDblClk`）も押下として扱う。ダブルクリックは 2 回の反転になり、元に戻る。
- **Rationale**: 暗い帯の上での見た目を揃えられる。標準のチェックボックスはフォーカスを持ち、Enter・Esc・Space の扱いがこのダイアログの方針とずれる。
  座標を CanSim に置いて checks で検証できる。
- **Alternatives considered**: `CButton`（`BS_AUTOCHECKBOX`）+ `WM_CTLCOLORBTN` で背景を暗くする方法。チェック欄の見た目は OS のテーマに依存し、暗い帯で読みにくい。

## 決定2: 配置（96 dpi、クライアント座標 = 帯の中）

- **Decision**:

  | 要素 | 範囲（x） | 範囲（y） |
  |---|---|---|
  | 終了ボタン（014、変更なし） | 〜168 | — |
  | チェックボックスのチェック欄 | `[186, 200)` | `[25, 39)`（14 px 角） |
  | チェックボックスの文字「フレーム表示」 | `[206, 290)` | `[22, 42)` |
  | チェックボックスの当たり判定 | `[182, 294)` | `[4, 60)` |
  | スピードスライダー | -13 の目盛り x 320、+10 の目盛り x 918（015 の 200 → 320） | — |
  | スライダーの当たり判定の右端 | 931 | — |
  | 時刻の欄の「シミュレーション時間」 | `[950, 1130)` | `[8, 28)` |
  | 時刻の欄の数値（右寄せ） | `[950, 1100)` | `[30, 54)` |
  | 時刻の欄の「μs」 | `[1104, 1130)` | `[30, 54)` |

  - チェック欄は、塗り `RGB(240,240,240)`・枠 `RGB(160,160,165)`。
  - チェックありのときは、欄の中に青 `RGB(30,110,200)` のレ点（太さ 2 px の折れ線）を描く。
  - 文字は白、高さ 12。
  - 時刻の欄の文字の色と大きさ:
    - 「シミュレーション時間」は `RGB(200,200,205)`、高さ 12。
    - 数値は白の太字、高さ 16。
    - 「μs」は `RGB(200,200,205)`、高さ 12。
- **Rationale**:
  - 数値は最大「600,000,000」の 11 文字。高さ 16 の太字で約 100 px に収まる。
  - 右端 1130 は、構成図の幅 1140 の内側で、クライアントの幅（約 1150）にも収まる。
  - スライダーを 120 px ずらしても、数字が重ならない間隔（015）は保てる。
- **Alternatives considered**: スライダーの間隔（26 px）を詰める。数字が読みにくくなるので採らない。

## 決定3: 時刻の表示の値

- **Decision**: メンバ `long long m_displaySimUs = 0` に持つ。
  | きっかけ | 値 |
  |---|---|
  | 起動 | 0 |
  | 「開始」で新しい実行（`OnSimStart` の Idle の分岐。`ResetDisplaysForRun` の中） | 0 |
  | 再生の書き換え（`AdvanceReplay`）・中断（`OnSimPause` 内の `AdvanceReplay`） | `m_curSimUs` |
  | 自然終了・即時完了（`FinishReplay`。開始時の +10、実行中の +10、終端到達） | `DurationSec × 1,000,000` |
  | 「終了」（`OnSimStop`） | `stopUs`（終了メッセージの時刻と同じ） |
  | 再開・スピード変更 | 変えない（次の書き換えで進む） |
  - 値が変わったら、時刻の欄だけを無効化する（`InvalidateRect(GetSimTimeRect(), FALSE)`）。
- **Rationale**: FR-007。中断中は書き換えが止まるので、数値も止まる。
  - 「終了」の値は終了メッセージと同じ `stopUs` を使う（SC-004）。
  - 終了メッセージ（モーダル）が出ている間も、表示は止まったまま正しい値になるよう、メッセージを出す前に値を入れて描き直す（`UpdateWindow`）。

## 決定4: 数値の書式

- **Decision**: `std::string FormatSimTimeUs(long long us)` を `SimControls` に置く。0 以上の整数を 3 けたごとに `,` で区切った ASCII 文字列を返す（負の値は 0 とする）。
  例: `0` → `"0"`、`1000` → `"1,000"`、`600000000` → `"600,000,000"`。
- **Rationale**: 純粋関数として checks で検証できる。ロケールに依存しない。

## 決定5: フレーム表示の切り替え

- **Decision**: `void ToggleFrameDisplay()` を追加する。中身は次のとおり。
  1. `m_settings.FrameDisplay = !m_settings.FrameDisplay`。
  2. 構成図とツールバーを無効化する。
  - `InRun()` による拒否はしない（Q1: A）。
  - `OnEditFrameDisplay`・`ON_COMMAND(ID_EDIT_FRAME_DISPLAY)`・`OnInitMenuPopup` の `CheckMenuItem` を削除する。
  - `.rc` のメニュー項目と `Resource.h` の `ID_EDIT_FRAME_DISPLAY` を削除する。
- **Rationale**:
  - FR-001〜FR-004。強調の対象 `m_active` は、フレーム表示の ON/OFF に関係なく書き換えごとに集めている（005 の作り）。そのため、実行中に ON にすると、次の書き換えから正しく描ける。
  - 中断中は `m_active` が中断の時点のまま残っているので、ON にするとその時点の強調を描ける。

## 決定6: 文字列（.rc）

- **Decision**:

  - `IDS_SIM_TIME_CAPTION` = 246「シミュレーション時間」

  - `_APS_NEXT_SYMED_VALUE` は 248 にする。
- **Rationale**: 日本語・ギリシャ文字は `.rc` に閉じ込める（CLAUDE.md）。
