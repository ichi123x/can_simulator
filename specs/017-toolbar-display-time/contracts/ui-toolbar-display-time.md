# UI Contract: フレーム表示のチェックボックスとシミュレーション時間

## ツールバー（左から）

開始・中断・終了のボタン → **フレーム表示のチェックボックス** → スピードスライダー → **シミュレーション時間**

## フレーム表示のチェックボックス

- 四角のチェック欄と「フレーム表示」の文字。チェックありは欄の中に青いレ点。
- チェック欄・文字のどちらをクリックしても、チェックが反転する。
- いつでも（待機・実行中・中断中・データフレーム編集中）操作できる。

| 状態 | チェックを入れた | チェックを外した |
|---|---|---|
| 待機 | 次の実行で強調を描く | 次の実行で強調を描かない |
| 実行中 | 次の書き換えから強調を描く | すぐに強調を消す |
| 中断中 | 中断した時点の強調をすぐ描く | すぐに強調を消す |

- 「編集」メニューの「フレーム表示」は無くなる。
- フレーム表示はプロジェクトに保存され（`FrameDisplay=`）、読み込むとチェックの状態に反映される。

## シミュレーション時間

- 上段「シミュレーション時間」、下段に数値（3 けた区切り、右寄せ）と「μs」。

| 状態 | 数値 |
|---|---|
| 起動直後 | 0 |
| 「開始」（新しい実行） | 0 から |
| 実行中 | 画面の書き換えごとに今のシミュレーション時刻 |
| 中断中 | 中断した時刻のまま |
| 自然終了・即時完了（+10） | シミュレーション時間の終端（例: 10,000,000） |
| 「終了」 | 停止時刻（終了メッセージの時刻と同じ） |

## 変えないもの

- 計算・CSV・ログ表示、ボタン・スライダーの動作、構成図・ログ表示エリアの位置、帯の高さ・ウィンドウの大きさ。
