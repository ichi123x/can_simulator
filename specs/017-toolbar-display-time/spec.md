# Feature Specification: ツールバーのフレーム表示チェックボックスとシミュレーション時間の表示

**Feature Branch**: `ver.0.3`（spec ディレクトリ: `017-toolbar-display-time`）

**Created**: 2026-10-01

**Status**: Draft

**Input**: User description: "編集メニューのフレーム表示はなくし、メニュー表示の下のアイコンエリアのシミュレーションとスライドボタンの間に、フレーム表示のチェックボックスを挿入してください。チェックボックスにチェックが入っている時は、フレーム表示をおこない。チェックが入っていない時は非表示とします。また、スライドボタンの右（画面の右端）にシミュレーション時間をラベル表示して、その下にシミュレーション時間をμsで表示します。単位"μs"のラベルも表示してください。"

**前提となる機能**: 機能 004（「編集 → フレーム表示」、プロジェクトファイルの `FrameDisplay=`）、機能 005（フレーム表示・再生の時計）、機能 007（実行中のメニュー制限）、機能 014（ツールバー・中断）、機能 015（スピードスライダー）、機能 016（受信 ECU の青）。

## 現状（背景）

- フレーム表示（構成図の送信・受信・バスの強調）の ON/OFF は「編集 → フレーム表示」で切り替える。実行中は「編集」メニューがグレーなので切り替えられず、開始時の設定のまま（機能 005/007）。
- 実行中のシミュレーション時刻は画面に表示されていない（ログの行の時刻からしか分からない）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ツールバーのチェックボックスでフレーム表示を切り替える (Priority: P1)

ユーザーはツールバーの、シミュレーションのボタン（開始・中断・終了）とスピードスライダーの間にある「フレーム表示」のチェックボックスで、
構成図の強調の表示・非表示を切り替える。「編集」メニューには「フレーム表示」は無い。

**Why this priority**: 要望の前半。メニューを開かずに切り替えられる。

**Independent Test**: 待機中にチェックボックスにチェックを入れて開始し、構成図の強調が出ることを確認する。チェックを外して開始し、強調が出ないことを確認する。「編集」メニューに「フレーム表示」が無いことを確認する。

**Acceptance Scenarios**:

1. **Given** 起動直後、**When** ツールバーを見る、**Then** 終了ボタンとスピードスライダーの間に「フレーム表示」のチェックボックス（四角のチェック欄と「フレーム表示」の文字）があり、チェックは入っていない（起動時のフレーム表示 OFF のまま）。
2. **Given** 待機中、**When** チェックボックス（チェック欄または文字）をクリックする、**Then** チェックが入る／外れる。
3. **Given** チェックが入っている、**When** 実行する、**Then** 構成図の送信 ECU・受信 ECU・バスが強調される（機能 005/016 のまま）。
4. **Given** チェックが入っていない、**When** 実行する、**Then** 構成図は強調されない。
5. **Given** 待機中、**When** 「編集」メニューを開く、**Then** 「フレーム表示」の項目は無い（「セッティング」「データフレーム編集」だけ）。
6. **Given** チェックを入れてプロジェクトを保存し、チェックを外してから読み込み直す、**When** 読み込みが終わる、**Then** チェックが入った状態に戻る（フレーム表示はプロジェクトに保存される）。
7. **Given** 実行中または中断中、**When** チェックボックスをクリックする、**Then** チェックが反転し、その場で構成図の強調の表示・非表示が変わる（チェックを入れたら次の書き換えから強調を描き、中断中は中断した時点の強調を描く。外したら強調を消す。ユーザー回答 Q1: A）。

---

### User Story 2 - シミュレーション時間を見る (Priority: P1)

ユーザーはツールバーの右端（スピードスライダーの右）で、「シミュレーション時間」のラベルの下に表示される時間の数値と単位「μs」を見る。

**Why this priority**: 要望の後半。実行の進み具合が数値で分かる。

**Independent Test**: スピード 0 で実行し、表示の数値が実時間とともに増え、中断で止まり、終了の時刻（終了メッセージの時刻）と一致することを確認する。

**Acceptance Scenarios**:

1. **Given** 起動直後、**When** ツールバーの右端を見る、**Then** 上の段に「シミュレーション時間」のラベル、その下の段に数値と単位「μs」のラベルが並ぶ。
2. **Given** いずれかの状態、**When** 数値を見る、**Then** 表示されるのは現在のシミュレーション時刻である（ユーザー回答 Q2: A）。起動直後は 0、実行中は画面の書き換えごとに進み、中断中は止まり、自然終了ではシミュレーション時間の終端の時刻、「終了」ではその停止時刻のまま、次の「開始」で 0 に戻る。
3. **Given** 数値が大きい（最大 600 秒 = 600,000,000 μs）、**When** 表示する、**Then** 数値はけたを省略せずに表示され、3 けたごとの区切り（,）が入る。表示欄からはみ出さない。

---

### Edge Cases

- チェックボックス・時間の表示を入れても、開始・中断・終了のボタンとスピードスライダーの機能は変えない（スライダーは右にずれてよい）。
- 古いプロジェクトファイルの `FrameDisplay=` はそのまま読み込み、チェックボックスに反映する。保存の形式は変えない。
- データフレーム編集中も、チェックボックスは操作できる（待機中のため）。
- 時間の表示の文字は、ツールバーの暗い帯の上で読める色にする。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 「編集」メニューから「フレーム表示」の項目を削除しなければならない。
- **FR-002**: ツールバーの、終了ボタンとスピードスライダーの間に、「フレーム表示」のチェックボックス（チェック欄と「フレーム表示」の文字）を置かなければならない。スピードスライダーはその分右へずらしてよい。
- **FR-003**: チェックボックスのチェック欄または文字をクリックすると、チェックが反転し、フレーム表示の設定が変わらなければならない。チェックありはフレーム表示 ON（構成図の強調を描く）、なしは OFF（描かない）。
- **FR-004**: チェックボックスは、待機・実行中・中断中・編集中のいつでも操作できなければならない。実行中・中断中に切り替えたら、その場で構成図の強調の表示・非表示を変えなければならない（中断中に ON にしたら、中断した時点の強調を描く）。
- **FR-005**: フレーム表示の設定は今までどおりプロジェクトに保存・読込みし、読込み後・起動直後のチェックの状態は設定と一致しなければならない。
- **FR-006**: ツールバーの右端（スピードスライダーの右）に、上段に「シミュレーション時間」のラベル、下段に時間の数値と単位「μs」のラベルを表示しなければならない。
- **FR-007**: 表示する値は現在のシミュレーション時刻（再生の時計、μs）とし、3 けたごとに区切って表示しなければならない。起動直後は 0、実行中は画面の書き換えごとに更新、中断中は止まる。自然終了ではシミュレーション時間の終端（例: 10 秒なら 10,000,000）、「終了」では停止時刻（終了メッセージの時刻と同じ値）を表示したまま、次の「開始」で 0 に戻す。スピード +10 の即時完了・実行中の +10 では終端の時刻を表示する。
- **FR-008**: シミュレーションの計算・CSV・ログ表示、構成図・ログ表示エリアの位置は変えてはならない。

### Key Entities

- **フレーム表示の設定**: ON/OFF。プロジェクトの一部（保存される）。チェックボックスのチェックと常に一致する。
- **シミュレーション時間の表示**: ラベル「シミュレーション時間」、数値（μs）、単位ラベル「μs」。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 「編集」メニューに「フレーム表示」が無く、フレーム表示の切り替えはツールバーのチェックボックスだけでできる。
- **SC-002**: チェックの有無と、実行中の構成図の強調の有無が 100% 一致する。
- **SC-003**: 保存・読込みでチェックの状態が保たれる（ON・OFF の両方で）。
- **SC-004**: 「終了」後の表示の数値が終了メッセージの停止時刻と一致し、自然終了後は終端の時刻と一致する。中断中は 5 秒待っても数値が変わらない。600,000,000 μs でも欄からはみ出さずに表示される。
- **SC-005**: 既存の検証（機能 001〜016）がすべて通り、シミュレーション結果（CSV）は変わらない。

## Assumptions

- チェックボックスと時間の表示は、機能 014・015 のツールバーと同じく暗い帯の上に描く（文字は白系）。
- チェックボックスはマウスのクリックで切り替える（キーボード操作は行わない。機能 015 と同じ方針）。
- 起動時のフレーム表示は OFF（機能 004 の既定値のまま）。
- 単位は「μs」（ギリシャ文字のミュー）と表記する。
- Q1・Q2 とも回答「A」（ユーザーの「Ａです」を両方の質問への回答と解釈した）。
- 実行中にフレーム表示を切り替えられるようになるため、機能 005 の「フレーム表示は開始時の設定のまま（実行中は切り替えられない）」はこの機能で置き換える。
