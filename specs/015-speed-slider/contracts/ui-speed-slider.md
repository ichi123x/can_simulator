# UI Contract: スピードスライダー

## 配置

- ツールバー（機能 014 の暗い帯）の、開始・中断・終了のボタンの右。
- 横線の溝の上に、-13（左端）〜+10（右端）の 24 個の目盛りが等間隔に並ぶ。各目盛りの下に数字（`-13` … `-1` `0` `+1` … `+10`）。
- つまみは縦長の長方形（棒）で、今のスピードの目盛りの位置にある。今の値の数字は太字・黄色。

## 操作（マウスだけ）

| 操作 | 結果 |
|---|---|
| つまみ・溝・目盛りの数字の上で押す | ポインタに一番近い目盛りへつまみが移り、その値になる |
| 押したまま左右に動かす | 目盛りを越えるたびに、つまみとスピードがその目盛りの値になる（帯の外へ出ても横の位置で追う） |
| 離す | その位置のまま |

- 待機・実行中・中断中・データフレーム編集中のいずれでも操作できる（グレーにならない）。

## スピードが変わったとき

| 状態 | 動作 |
|---|---|
| 待機 | 値が変わるだけ。次の「開始」から、その値で進む（+10 なら即時完了）。 |
| 実行中（+10 以外） | その瞬間のシミュレーション時刻から、新しいスピード（実経過時間 × 2^スピード）で進む。時刻は飛ばない・戻らない。 |
| 中断中（+10 以外） | 時刻は止めたまま。再開から新しいスピード。 |
| 実行中・中断中で +10 | その場で最後まで進めて完了（全行の表示・全結果の CSV・完了メッセージ・待機へ）。 |

## セッティング

- 「編集 → セッティング」は ECU 数・通信速度・シミュレーション時間の 3 項目になる（スピードの項目は無い）。

## 保存・読込み

- スピードは今までどおりプロジェクトに保存される（`[Project] Speed=`）。読み込むと、つまみはその値の目盛りへ移る。

## 変えないもの

- 計算・CSV・ログの行の内容、スピードの意味（機能 005）、ツールバーのボタン（機能 014）、構成図・ログ表示エリアの位置。
