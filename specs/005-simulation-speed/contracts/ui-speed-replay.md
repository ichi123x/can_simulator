# UI Contract: スピード欄と再生

## セッティング画面（004 の `IDD_SETTINGS` に追加）
| コントロール | 内容 |
|---|---|
| スピード | ドロップダウンリスト、`+10` `+9` … `+1` `0` `-1` … `-13` の 24 項目（上から降順）。初期値 0 |
| 注記 | 「(+10: 即時 / 0: 実時間 / -13: 1/8192)」 |

実行中はセッティングを開けない（004 と同じ）。

## 再生
| 項目 | 規則 |
|---|---|
| 時計 | シミュレーション時刻 = 再生開始からの実経過時間 × 2^スピード（+10 は再生せず即時完了） |
| 書き換え | 約 16 ms 間隔（目標）。1 秒間に 30 回以上 |
| 強調の対象 | 直前の書き換えから今回までの時刻区間に送信中だったフレーム |
| 送信元 ECU | 赤系（004 と同じ）。複数あればすべて |
| 受信 ECU | 緑系（004 と同じ）。送信元にも該当する ECU は赤を優先 |
| バス | 区間内にフレームがあれば青系（004 と同じ） |
| フレーム表示 OFF | 強調を描かない。時計と所要時間は ON と同じ |
| 実行中のフレーム表示切替 | 可。強調の有無だけが変わる |
| 終端 | シミュレーション時間に達したら CSV を書き、完了を通知 |
| 終了（メニュー） | 現在の時計の時刻までの結果を出力し、終了を通知 |

この表は 004 の `contracts/ui-menu-dialogs.md` の「再生表示」（1 フレーム 250 ms 固定、空き時間スキップ）を
置き換える。
