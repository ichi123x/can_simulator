# Data Model: ウィンドウの最小化・最大化ボタンとスピードの範囲の変更

## スピード（`ProjectSettings::Speed`、既存）

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 範囲 | -13〜+10（`kMinSpeed` = -13） | -10〜+10（`kMinSpeed` = -10） |
| 意味 | シミュレーション時刻 = 実経過時間 × 2^Speed。+10（`kInstantSpeed`）は即時完了 | 同じ |
| 読込み | -13〜+10 以外はエラー | -13〜-11 は -10 にする（`kLegacyMinSpeed` = -13）。-14 以下・+11 以上はエラー（文言は -10〜10） |
| 保存 | `Speed=<値>` | 同じ（値は常に -10〜+10） |
| 変更（スライダー） | `SetSpeed` が `kMinSpeed`〜`kMaxSpeed` に切る | 同じ式で -10〜+10 に切る |

## メインウィンドウの状態（Windows が持つ、新規の保持なし）

```text
通常 ──「_」/ システムメニュー / Win+↓──> 最小化 ──タスクバー / Alt+Tab──> 通常（最小化前が最大化なら最大化）
通常 ──「□」/ タイトルバーのダブルクリック / Win+↑──> 最大化 ──「元に戻す」/ ダブルクリック / Win+↓──> 通常（最大化前の大きさ・位置）
```

アプリは状態を保存しない。実行の状態（`m_runPhase`）・時刻・表示は、ウィンドウの状態に関係なく続く。
