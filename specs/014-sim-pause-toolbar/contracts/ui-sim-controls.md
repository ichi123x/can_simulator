# UI Contract: シミュレーションのメニューとツールバー

## メニュー「シミュレーション」

| 項目 | 動作 |
|---|---|
| 開始(&R) | 待機: 新しい実行を始める（機能 004/005/012 のまま）。中断中: 中断した時点から再開する。 |
| 中断(&P) | 実行中: 表示を今の時刻まで進めてから止める（ログの行・構成図の強調・時刻が止まる）。 |
| 終了(&X) | 実行中・中断中: その時点（中断中は中断した時刻）までの結果を出力して待機に戻る（機能 005 のまま）。 |

## ツールバー（メニューの下の段）

- 暗い帯の左から「開始」（緑の右向き三角）・「中断」（青の縦 2 本線）・「終了」（赤の四角）の角丸ボタン。記号の下に名前。
- 押して離すと（同じボタンの上で）、対応するメニュー項目と同じ動作。押下中は箱が少し暗くなる。押したまま外へ出て離すと何もしない。
- 無効のボタンはグレー（箱・記号・名前とも）で、押しても何もしない。

## 有効／無効（メニューとボタンで常に同じ）

| 状態 | 開始 | 中断 | 終了 |
|---|---|---|---|
| 待機 | 有効（データフレーム編集中は無効） | 無効 | 無効 |
| 実行中 | 無効 | 有効 | 有効 |
| 中断中 | 有効（再開） | 無効 | 有効 |

## 中断中

- 「ファイル」「編集」メニューはグレー（機能 007 と同じ）。ECU のダブルクリックで編集ウィンドウは開かない（機能 010 と同じ）。
- 構成図の強調は中断した時点のまま（フレーム表示 ON のとき）。ログ表示エリアはスクロール・ホイールで読める。
- 待っている間の実時間はシミュレーション時刻に数えない。

## 画面の配置

- ウィンドウはツールバーの高さ（96 dpi で 64 px）だけ縦に大きくなる。構成図・ログ表示エリア・枠・スクロールバーは、大きさ・互いの位置関係を
  変えずに、その分だけ下へずれる。

## 変えないもの

- 計算・CSV・ログの行の内容、時間の進み方（スピード）、「開始」の前の保存先の確認、開始時の表示の初期化（機能 012）。
