# Quickstart: 014 の検証

## 1. コアの検証（自動、checks.exe）

ビルド・実行の方法は CLAUDE.md と `tools/cansim_runner/README.md` を参照。

- 014 の新しい項目:
  - `GetSimCommandStates` が [data-model.md](./data-model.md) の表の 8 通り（Idle×編集中 2 通り、Running・Paused × 2 通り）と一致する。
  - ツールバー（DPI 96/120/144）:
    - 3 つのボタンが帯の中に収まり、互いに重ならず、左から順に並ぶ。
    - `FindSimButtonAt` が各ボタンの角の内側・外側で、描画の範囲（`[Left, Right) × [Top, Bottom)`）と一致する。
    - 帯の下端は、ずらした後の構成図の上端と一致する（重ならない）。
  - `ResumedSimTimeUs`:
    - 基準 0 では `SimTimeAtUs` と同じ値になる。
    - 中断・再開を何回くり返しても、経過時間の合計が同じなら同じ時刻になる（スピード 0）。
    - 大きな値で飽和する。
- 既存の 001〜013 の項目がすべて PASS し、サンプルの CSV が基準と一致する。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー）

詳しい動作は [contracts/ui-sim-controls.md](./contracts/ui-sim-controls.md) を参照。

1. 起動直後: メニューの下に暗い帯と 3 つのボタンがある。
   - 「開始」だけが有効の色で、「中断」「終了」はグレー。
   - 「シミュレーション」メニューは「開始」「中断」「終了」の順で、有効／無効がボタンと同じ。
   - 構成図とログ表示エリアは帯の下にあり、大きさ・枠は機能 011 のまま。ECU のダブルクリックは、箱の上で反応し、箱の外では反応しない（ずらしの確認）。
2. データフレーム編集を開く → 「開始」ボタン・メニューがグレー。閉じると有効に戻る。
3. `sample_appendix_a`（スピード 0、10 秒）で「開始」ボタン → 「開始」グレー、「中断」「終了」有効。
4. 3 秒後に「中断」ボタン:
   - 0.1 秒以内にログの行数が増えなくなる。
   - 10 秒待っても行数・表示は変わらない。
   - 「開始」「終了」が有効、「中断」がグレーになる。
   - 「ファイル」「編集」メニューはグレーのまま。
5. 中断中にログ表示エリアをホイールで遡れる。ECU のダブルクリックで編集ウィンドウが開かない。
6. 「開始」ボタンで再開:
   - 保存先を尋ねず、ログは消えずに続きの行が出る。
   - 中断の直前の行の次の行から続き、欠けも重複もない。
   - 最後まで実行すると完了メッセージが出る。
   - CSV は、中断せずに実行したものと一致する。
7. 中断・再開を 5 回くり返して最後まで実行する → CSV は中断なしと一致し、ログの行数は全行数と同じ（SC-003）。
8. 実行中に「中断」→「終了」:
   - 完了メッセージの時刻は中断した時刻になる。
   - `.log.csv` の最後の行の時刻は中断の時刻を超えない（SC-004）。
   - 待機に戻り、「開始」だけが有効になる。
9. スピード +10 の構成で「開始」→ すぐ完了して待機に戻る（「中断」は押せない）。
10. ボタンを押したまま外へ出て離す → 何も起きない。グレーのボタンを押しても何も起きない。
