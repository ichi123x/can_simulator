# Data Model: 012 開始時の表示の初期化

新しい保存データ・新しいメンバはない。「開始」で次の既存メンバを初期状態に戻す。

| メンバ | 初期状態 | 由来 |
|---|---|---|
| `m_logLines` | 空 | 機能 009 |
| `m_logShown` | 0 | 機能 009 |
| `m_logTop` | 0（先頭） | 機能 009 |
| `m_grayEcu` | 0（なし）。グレーのタイマーも止める | 機能 011 |
| `m_active` | 空（送信・受信・バスの強調なし） | 機能 005 |

## 「開始」の処理の順序

| 順 | 処理 | 区分 |
|---|---|---|
| 1 | 実行中・編集中なら何もしない | 前提の確認 |
| 2 | 保存先が無ければ尋ねて保存する（キャンセル・失敗なら終わり） | 前提の確認 |
| 3 | `ResetDisplaysForRun()`: 上の表のメンバを戻し、構成図とログ表示エリアをその場で描き直す | 表示の初期化（本機能） |
| 4 | 実行用ネットワークの生成・計算・ログ行の作成（待機カーソル） | 計測関連の初期化 |
| 5 | スピード +10 なら完了処理。それ以外は再生の時計・強調・タイマーの準備 | 計測関連の初期化 |
