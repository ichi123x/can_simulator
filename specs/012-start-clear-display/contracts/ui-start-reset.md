# UI Contract: 「開始」時の表示の初期化

## 「シミュレーション → 開始」

| 状況 | 表示 |
|---|---|
| 保存先を尋ねてキャンセル、または保存に失敗 | 何も変えない（前回のログ・スクロール位置・構成図のまま） |
| 実行が決まった（保存先あり） | 計算の前に、次をその場で画面に反映する：<br>・ログ表示エリアを空にする（スクロールバーは行なし・位置は先頭）<br>・構成図の強調・グレー表示を消す |
| 計算中（待機カーソル） | 上の空の状態のまま |
| 再生中 | 最初の行がログ表示エリアの一番上に出て、以後は上から順に並ぶ。エリアを超えた後の追従は機能 009 のまま |
| 完了・「終了」の後 | 機能 009 のまま（行は次の「開始」まで残る） |

## 変えないもの

- 計算・CSV・ログの行の内容と順序、時間の進み方（機能 005）。
- 開始の可否（実行中・編集中は選べない。機能 007・010）。
