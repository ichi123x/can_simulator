# UI Contract: 構成図領域とダイアログ

| 項目 | 値 |
|---|---|
| 表示部背景 | RGB(255,255,255) 固定 |
| 図領域 | ダイアログクライアント左上、1140×216 px（96 dpi 基準、DPI スケール適用） |
| バス線 | 黒、4 px、図領域の左右 10 px 余白内に全幅 |
| 見出し | 「CAN BUS」太字、バス線の左上 |
| ECU ラベル | 「ECU NN」（NN は2桁ゼロ埋め） |
| 奇数 ECU | バス線の上、薄紫の角丸箱＋接続線 |
| 偶数 ECU | バス線の下、薄橙の角丸箱＋接続線 |
| ECU 中心間隔 | 56 px（ECU 数によらず一定）。ECU 01 の接続線 x=150、ECU 16 は x=990 |
| バス両端の余裕 | バス線は x=10〜1130。両端から最初/最後の ECU の接続線まで 140 px 空け、見出しと接続線を重ねない |
| ECU 0 個 | 見出しとバス線のみ |
| ダイアログ初期サイズ | クライアント720×152 DLU（16 ECU が収まる。メニュー行は含まない） |

既存コントロールの扱い（削除）は機能 004 が定める。本機能は図領域の描画と、それが収まるダイアログ寸法のみを規定する。
