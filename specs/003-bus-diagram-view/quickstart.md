# Quickstart: CAN バス構成図の表示の検証

## 1. レイアウト計算の検証（自動）
リポジトリ直下で、CLAUDE.md の手順どおり `checks.exe` をビルド・実行する。追加項目（ECU 数 0/1/6/16、奇偶配置、間隔一定、ECU 01/16 の接続線位置、見出しとの非重複、図領域内収まり、範囲外クランプ）がすべて PASS すること。

## 2. 目視確認（GUI）
`msbuild MFCApplication1\MFCApplication1.sln /p:Configuration=Debug /p:Platform=x64` でビルドし起動。ECU 数の入力手段は機能 004 のセッティングで提供される。004 の完成前は、`m_ecuCount` の初期値を一時的に書き換えて（0 / 2 / 6 / 16）再ビルドして確認する（コミットしない）。
1. ECU 数=0: 白背景に「CAN BUS」とバス線のみ、ECU なし（SC-003, US3）。
2. ECU 数=6: ECU 01〜06 が上下交互に表示される（US1）。
3. ECU 数=16: ECU 01〜16 が欠け・重なりなく初期サイズのまま収まる。参考画像（`Doc/CANバスイメージ(最大時 ECU=16).jpg`、`Doc/CANバスイメージ(最小時 ECU=0).jpg`）と見比べる（SC-001/005）。
4. 見出し「CAN BUS」の文字が ECU 01 の接続線と重ならない（SC-006）。
5. ECU 数の変更がキャンセル・失敗した場合に図が変わらないことは、機能 004 のセッティング／プロジェクト読込みの完成後に確認する（FR-010）。
6. Windows をダークテーマにしても表示部が白のままであること（SC-004）。

## 3. ビルド
Debug/Release × x64/x86 の4構成でビルドが通ること（憲章 II）。
