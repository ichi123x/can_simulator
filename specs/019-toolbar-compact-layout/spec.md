# Feature Specification: ツールバーの並びの入れ替えとボタン・スライダーの縮小

**Feature Branch**: `ver.0.3`（spec ディレクトリ: `019-toolbar-compact-layout`）

**Created**: 2026-10-01

**Status**: Draft

**Input**: User description: "シミュレーション時間の表示とスライドボタンの位置を入れ替えてください。また、シミュレーションアイコン、スライドボタンの大きさは今の半分にして、スライドボタンの左には、スピード：ラベルを付けてください。"（確認の回答: Q1 = A、Q2 = A）

**前提となる機能**: 機能 014（ツールバーのボタン）、015（スピードスライダー）、017（フレーム表示チェックボックス・シミュレーション時間）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 小さくまとまったツールバーを使う (Priority: P1)

ユーザーはツールバーで、左から 開始・中断・終了のボタン（今の半分の大きさ）→ フレーム表示のチェックボックス → シミュレーション時間 →「スピード：」のラベルとスピードスライダー（今の半分の大きさ）の順に並んだ部品を使う。操作と動きは今までと同じ。

**Why this priority**: 要望のすべて。

**Independent Test**: 起動直後の画面写しで並びと大きさを確かめ、各ボタン・チェックボックス・スライダーを新しい位置で操作して今までどおり動くことを確かめる。

**Acceptance Scenarios**:

1. **Given** 起動直後、**When** ツールバーを見る、**Then** 左から ボタン 3 つ → チェックボックス → シミュレーション時間 → 「スピード：」→ スライダーの順に並ぶ。
2. **Given** 同じとき、**When** ボタンを見る、**Then** 箱と記号は今の半分の大きさ（96 dpi で 24 × 18 px）で、名前（開始・中断・終了）は箱の下に小さな文字で表示される（Q2: A）。有効／無効・押下の見た目の規則は今までどおり。
3. **Given** 同じとき、**When** スライダーを見る、**Then** 長さ・つまみ・溝は今の半分で、目盛りは 24 個のまま。数字は 5 刻み（-13・-10・-5・0・+5・+10）と、今の値（太字・黄色）だけを表示する。今の値の数字と重なる 5 刻みの数字は表示しない（Q1: A）。
4. **Given** 同じとき、**When** スライダーの左を見る、**Then** 「スピード：」のラベルがある。
5. **Given** 新しい位置、**When** ボタン・チェックボックスを押す、スライダーをクリック・ドラッグする、**Then** 今までどおりに動く（目盛りへの丸め・実行中の変更・+10 の即時完了を含む）。

### Edge Cases

- ツールバーの帯の高さ（64 px）、構成図・ログ表示エリアの位置、ウィンドウの大きさは変えない。
- 部品どうしは重ならず、すべて帯の中・ウィンドウの幅の中に収まる（DPI 96/120/144）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ツールバーの並びを、ボタン → チェックボックス → シミュレーション時間 → 「スピード：」→ スライダー にしなければならない。
- **FR-002**: ボタン（箱・記号）を今の半分の大きさにし、名前は箱の下に小さな文字で表示しなければならない。
- **FR-003**: スライダー（目盛りの間隔・つまみ・溝）を今の半分の大きさにしなければならない。目盛りは -13〜+10 の 24 個のまま。
- **FR-004**: スライダーの数字は、5 刻みの値（-13・-10・-5・0・+5・+10）と今の値を表示し、今の値から 2 目盛り以内の 5 刻みの数字は表示してはならない。
- **FR-005**: スライダーの左に「スピード：」のラベルを表示しなければならない。
- **FR-006**: ボタン・チェックボックス・スライダー・シミュレーション時間の動作、構成図・ログ表示エリアの位置、計算・CSV は変えてはならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 部品が FR-001 の順に重ならずに並び、帯とウィンドウの幅に収まる（DPI 96/120/144）。
- **SC-002**: 表示される数字どうしが重ならない（今の値が -13〜+10 のどれでも）。
- **SC-003**: 新しい位置で、ボタン・チェックボックス・スライダーの操作が今までどおりに動く。
- **SC-004**: 既存の検証（機能 001〜018）がすべて通り、シミュレーション結果（CSV）は変わらない。

## Assumptions

- 「半分の大きさ」は、ボタンは箱と記号の幅・高さ、スライダーは目盛りの間隔・つまみ・溝の太さを半分にすることとする。
- ボタンの名前の文字は 10 px（96 dpi）程度にする。シミュレーション時間・チェックボックスの文字の大きさは変えない。
- 「スピード：」は日本語の文字列として `.rc` の文字列テーブルに置く。
