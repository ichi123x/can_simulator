# Data Model: 013 一覧のダブルクリックでフレーム追加

新しい保存データはない。プロジェクトの定義（`m_definitions`）・`.canprj` の形式は変わらない。

## 追加する要素（`CFrameEditDlg`）

| 要素 | 内容 |
|---|---|
| `m_header`（`CFrameListHeader`） | 一覧の列見出しをサブクラス化したもの。`WM_LBUTTONDBLCLK` を受けたら、既定の処理をせずに編集ウィンドウへ `WM_APP_FRAME_LIST_ADD` を送る |
| `WM_APP_FRAME_LIST_ADD`（`WM_APP + 2`） | 列見出しから編集ウィンドウへの「一覧から追加」の要求。編集ウィンドウの中だけで使う |
| `CanAdd()` | ECU が選ばれていて、その ECU のフレームが 100 件未満なら真。「追加」ボタンの有効／無効と、ダブルクリックの受付の両方の条件 |
| `AddFromList()` | `CanAdd()` が真なら `OnAdd()`（「追加」ボタンと同じ処理）、偽なら何もしない |

## ダブルクリックの場所と動作

| 場所 | 届くもの | 動作 |
|---|---|---|
| 行の上 | `NM_DBLCLK`（行の番号あり） | `AddFromList()`（行は 1 回目のクリックで選ばれる） |
| 行の無い空白（0 件の一覧全体を含む） | `NM_DBLCLK`（行の番号 -1） | `AddFromList()` |
| 列見出し（項目・境目・最後の列より右） | 列見出しの `WM_LBUTTONDBLCLK` → `WM_APP_FRAME_LIST_ADD` | `AddFromList()`（列幅の自動調整はしない） |
| スクロールバー | 一覧の非クライアントのダブルクリック（`NM_DBLCLK` は出ない） | 何もしない（スクロールの操作のまま） |

## `CanAdd()` が偽のとき

| 状況 | 動作 |
|---|---|
| ECU 数 0（ECU を選べない） | 何もしない |
| 選んだ ECU のフレームが 100 件 | 何もしない（メッセージなし） |
