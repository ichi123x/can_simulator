# UI Contract: 送信フレーム一覧のダブルクリック

対象: 「編集 → データフレーム編集」ウィンドウの送信フレーム一覧（列見出しを含む一覧全体）。

## ダブルクリック

| 場所 | 「追加」ボタンが有効なとき | 「追加」ボタンが無効なとき（ECU なし・100 件） |
|---|---|---|
| 行の上 | 追加の入力画面を開く（その行は選ばれる。編集は開かない） | 何もしない |
| 行の無い空白 | 追加の入力画面を開く | 何もしない |
| 列見出し（項目・境目・右の空き） | 追加の入力画面を開く（列幅の自動調整はしない） | 何もしない |
| スクロールバー | 何もしない（スクロールのまま） | 何もしない |

## 追加の入力画面を開いた後

「追加」ボタンからの場合とまったく同じ（機能 006・010）。

- 入力画面は追加用（空欄・既定値）。OK で入力を検査し、NG なら「項目: 理由」を示して閉じない。
- OK で通ったフレームは一覧の末尾に加わり、その行が選ばれる。キャンセルでは定義を変えない。
- 入力画面の表示中は、メインダイアログは無効。

## 変わるもの・変えないもの

- 変わる: 一覧の行のダブルクリックは「編集」ではなく「追加」になる（機能 006 の取り決めを置き換える）。
- 変えない: 「追加」「編集」「削除」「閉じる」ボタンの動作と有効／無効、列幅のドラッグでの変更、プロジェクトへの反映・保存、
  シミュレーション結果。
