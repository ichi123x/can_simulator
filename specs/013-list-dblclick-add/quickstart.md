# Quickstart: 013 の検証

## 1. コアの検証（自動、checks.exe）

- 既存の 001〜012 の項目がすべて PASS し、サンプルの CSV が基準と一致する（コアは変更しない）。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー）

アプリを起動し、「編集 → データフレーム編集」を開く（または ECU をダブルクリック）。「追加の入力画面が開いた」ことは、入力画面（`IDD_FRAME_ENTRY`）のウィンドウが現れることで判定する。確認ごとにキャンセルで閉じる。詳しい動作は [contracts/ui-frame-list-dblclick.md](./contracts/ui-frame-list-dblclick.md) を参照。

1. 起動直後（ECU 01 はフレーム 0 件）の一覧の中央をダブルクリックする → 追加の入力画面が開く。値を入れて OK → 1 行目に加わって選ばれる。
2. その行の上をダブルクリックする → 編集ではなく追加の入力画面が開く（空欄）。キャンセル → 一覧は変わらず、その行が選ばれたまま。
3. 最後の行より下の空白をダブルクリックする → 追加の入力画面が開く。
4. 列見出しの項目（例: 「フレーム名」）・列の境目・最後の列より右の空きをそれぞれダブルクリックする → どれも追加の入力画面が開く。境目のダブルクリックで列幅は変わらない。
5. 列見出しの境目をドラッグする → 列幅が変わる（今までどおり）。
6. 行をスクロールバーが出るまで追加し（`sample_16ecu` 等で行の多い ECU、または追加を繰り返す）、スクロールバーの矢印・つまみをダブルクリックする → 追加の入力画面は開かない。
7. フレームが 100 件の ECU（一時フォルダの `.canprj` に 100 件のフレームを書いたもの）を選び、一覧の行・空白・列見出しをダブルクリックする → 何も開かない（メッセージも出ない）。
8. ECU 数 0 のプロジェクトで一覧をダブルクリックする → 何も開かない。
9. 「追加」ボタンから同じ値で追加したフレームと、ダブルクリックから追加したフレームで、プロジェクト保存後のファイルの内容が同じ形になる。
10. 「編集」ボタンは今までどおり、選んだ行の編集の入力画面を開く。
