# UI Contract: フレーム表示の受信 ECU

フレーム表示 ON の実行中（中断中は中断した時点の表示のまま）、画面の書き換えごとに、その間にバス上にあったフレームについて次のとおり描く。

| 対象 | 表示 |
|---|---|
| 送信 ECU | 赤の箱（太い枠）、接続線は青の太線（変更なし） |
| 受信 ECU | **青の箱（明るい青の塗り、バスと同じ青の枠）、接続線は青の太線** |
| 受信しない ECU | 元の色、細い黒の接続線 |
| バス | フレームがある間は青の太線、空いていれば黒（変更なし） |

- バスが空いている書き換えでは、赤・青の ECU も青い接続線も描かない。
- フレーム表示 OFF・待機中は、強調しない（変更なし）。
- 同じ ECU が送信と受信の両方に当たる場合は送信（赤）。
