# Quickstart: 011 の検証

## 1. コアの検証（自動、checks.exe）

- ECU 数 0〜16 × DPI 96/120/144 で、`Frame` を換算した矩形が構成図の領域の内側にあり、バス線・「CAN BUS」の文字の範囲（x 14〜118、
  y 80〜106）・各 ECU の箱・接続線がその内側で、線と重ならない（換算後に 1 px 以上離れている）。
- 既存の 001〜010 の項目が PASS のまま。CSV が変わらない。
- 補足（動作に影響なし）: 上の「CAN BUS」の文字の範囲 x 14〜118 は `kCaptionRight` による目安で、実際の文字は x 約 131 まで描かれる
  （125% の画面から逆算）。checks.exe は文字を描く枠全体（x 14〜158、y 76〜106）で確かめているので、判定はこの差を含んでいる。

## 2. GUI の確認（Debug|x64、サンプルは一時フォルダにコピー、ダブルクリックは実マウス入力）

グレーの判定は、ECU の箱の中の文字にかからない点（箱の左端から 8 px、上下の中央）の画面の色を読む。

1. `sample_appendix_a` を読み込み「ECU 03」をダブルクリック → 0.1 秒以内に ECU 03 の点がグレー（`RGB(205,205,205)`）になり、0.4〜0.7 秒で
   もとの色に戻る。ほかの ECU の点の色は変わらない。編集ウィンドウはすぐ開く。
2. 開いたまま「ECU 03」をもう一度ダブルクリック → ECU 03 が約 0.5 秒グレー、編集ウィンドウのハンドルは同じ。
3. 開いたまま「ECU 05」をダブルクリック → ECU 05 がグレーになり、約 0.5 秒後に戻るのとほぼ同時（差 0.1 秒以内）に ECU 05 の編集ウィンドウが
   開く。閉じてから開くまでは機能 010 と同じ 0.4〜0.7 秒。
4. 「ECU 03」をダブルクリックし 0.2 秒後に「ECU 05」をダブルクリック → ECU 03 はすぐ戻り、ECU 05 だけが 2 回目から約 0.5 秒グレー。
5. `sample_startup`（スピード 0）の実行中に ECU をダブルクリック → グレーにならない。バス線・余白・ログ表示エリアのダブルクリック、ECU の
   1 回クリック → グレーにならない。「追加」の入力画面の表示中に別の ECU をダブルクリック → グレーにならない。
6. ECU 06 をダブルクリックした直後（0.5 秒以内）に編集ウィンドウを閉じて「セッティング」で ECU 数を 2 にする → ECU 06 のグレーは残らず、
   ECU 数を 6 に戻しても ECU 06 は通常の色。
7. 構成図とログ表示エリアの枠: ECU 数 0・6・16、実行中（フレーム表示 ON）、ログをスクロールした状態のスクリーンショットで、2 つの枠が同じ
   位置に欠けずに表示され、ECU・バス線・「CAN BUS」の文字・ログの文字・スクロールバーと重ならない。拡大率は実機の値（125%）で確認し、
   100%・150% は checks の計算検証で代える。
