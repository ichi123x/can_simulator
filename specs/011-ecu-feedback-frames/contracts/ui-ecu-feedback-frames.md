# UI Contract: ECU のグレー表示と表示エリアの枠

## グレー表示

| 操作 | グレー表示 |
|---|---|
| 実行中でない状態で ECU k の箱をダブルクリック（機能 010 で開く・前面に出す・切り替える・待ちの間に置き換える） | ECU k をすぐにグレーにし、最後のダブルクリックから 500 ms 後に戻す。前にグレーだった ECU はすぐ戻す |
| 実行中のダブルクリック | しない |
| ECU の箱の外（バス線・文字・接続線・余白・ログ表示エリア・枠の線）のダブルクリック | しない |
| 1 回クリック | しない |
| 入力画面・削除確認の表示中（メインウィンドウ無効） | しない（届かない） |
| グレー表示中に ECU 数の変更でその ECU が無くなる／「開始」 | 取り消す |

- グレーの配色: 塗り・枠・文字とも無彩色（data-model.md）。ほかの ECU・バス線・接続線は変えない。
- 機能 010 の動作と時間（すぐ開く、閉じて 500 ms 後に開く、前面に出す）は変えない。

## 枠

| 領域 | 枠の位置（96 dpi、画面の拡大率で換算） |
|---|---|
| 構成図 | 構成図の領域の 4 px 内側: (4, 4) - (1136, 212) |
| ログ表示エリア（灰色の領域 + スクロールバー） | 3 px 外側: (147, 257) - (1003, 523) |

- 線はグレー 1 px（換算、最小 1）。ECU 数・実行状態・フレーム表示・ログのスクロールで変わらない。
- 枠は表示だけで、ダブルクリックの判定・ホイールの範囲・ウィンドウの大きさは変えない。
