# UI Contract: 流れのエフェクト

フレーム表示 ON の実行中（中断中は止まった形で）、構成図の強調（送信 ECU 赤・受信 ECU 青・青い線とバス）の上に重ねて描く。

| 要素 | 見た目 |
|---|---|
| 粒 | 明るい黄色の小さな円（白い縁）。送信 ECU の箱の縁から、その接続線を通ってバスへ、バスを受信 ECU の接続点まで、受信 ECU の接続線を通って箱の縁へ進む。道筋 1 本に 3 個、0.6 秒で 1 周する。 |
| 送信の光 | 粒が出た直後、送信 ECU の箱の外側に黄〜白の枠が光る（すぐ弱まる）。 |
| 受信の光 | 粒が届く直前、受信 ECU の箱の外側に黄〜白の枠が光る。 |

- 粒が通るのは、強調されている送信 ECU と受信 ECU の接続線とバスだけ。受信しない ECU・その線には行かない。
- バスが空いている書き換えでは描かない。待機中・フレーム表示 OFF では描かない。
- 動きの速さはスピードに関係なく一定。中断中は止まり、再開で続きから動く。
- 箱の塗り（赤・青）と ECU 名には重ねない（光は箱の外側の枠）。
